# 🧮 Prime Number Generator with Web Worker

A simple React + Vite project demonstrating how to use Web Workers to calculate prime numbers without blocking the UI.

## 🚀 Features

- Multi-threaded prime number generator
- Progress updates from the worker
- Responsive UI using React
- Built with Vite

## 🧰 Technologies

- React
- Web Workers
- Vite
- react-toastify

## 📦 How to Run

```bash
git clone https://github.com/your-username/prime-worker-app.git
npm install
npm run dev
